**Thesis:** Ship `turn`, surface `function_tool`, prove the registry contract with one TS port. That's it.

**Goal:** Make kaji's two distinctive wedges — the **shadcn-style integration registry** ([`kaji/sdk/kaji/integrations/registry/index.json`](kaji/sdk/kaji/integrations/registry/index.json)) and the **provider-neutral toolgen** ([`kaji/sdk/kaji/runtime/tools/payload.py`](kaji/sdk/kaji/runtime/tools/payload.py)) — usable from the first line a developer writes in either SDK. This is DX-focused work, not assimilation with Vercel AI SDK or Flue. No `generateText` / `generateObject` clone in this branch; structured output via toolgen is a follow-up once the wedges land.

**Honest framing:** Two of four tasks land the wedges directly (Task 2 toolgen visibility, Task 3 registry contract). The other two (Task 0 mock options, Task 1 `turn`) unblock the canonical example so it shrinks to 5 lines — `turn` is **not** a wedge, it exists because Task 2's example must be readable in one glance. `kaji/serve` parity is downstream of this plan (serve needs `turn` to call) and tracked separately.

**Effort:** ~2 human-days for a careful engineer. Task 0: 2h. Task 1: 4h. Task 2: 3h. Task 3: 4h (echo integration; gmail port is deferred — see Out of Scope). Single branch, four commits, one PR.

- Semantics, both SDKs:

**Interfaces:**
- Consumes: existing `runtime.send(session_id, prompt)` ([`runtime.py:152`](kaji/sdk/kaji/runtime/agents/runtime.py:152)), existing `store.get_events(sid)` / `store.getEvents(sid)`, existing `SessionCreated(session_id=...)` event (the schema accepts ONLY `session_id` per [`schemas.py: class SessionCreated(BaseEvent)`](kaji/sdk/kaji/infra/events/schemas.py) — `BaseEvent` supplies the rest).
- Produces (Python):
  ```python
  @dataclass(frozen=True)
  class TurnResult:
      text: str
      tool_call_events: list[KajiEvent]  # ToolCallRequested events emitted this turn
      session_id: str
      events: list[KajiEvent]             # all events emitted this turn

  async def turn(
      self,
      prompt: str,
      *,
      session_id: str | None = None,
  ) -> TurnResult: ...
  ```
- Produces (TS):
  ```ts
  interface TurnResult {
    text: string;
    toolCallEvents: KajiEvent[];
    sessionId: string;
    events: KajiEvent[];
  }
  async turn(prompt: string, opts?: { sessionId?: string }): Promise<TurnResult>
  ```
- Naming choice: `turn` matches existing internal vocabulary (`run_turn` at [`runtime.py:152`](kaji/sdk/kaji/runtime/agents/runtime.py:152)). The field is `tool_call_events` (not `tool_calls`) because the value is `KajiEvent`s, not provider-neutral `ToolCall` payloads — naming follows the type honestly.
- `session_id` defaults to a fresh UUID (Python: `uuid.uuid4().hex`; TS: `crypto.randomUUID()`).
- **Session bootstrapping**: if `store.get_events(sid)` returns an empty list, both `store.append(SessionCreated(session_id=sid))` AND `bus.publish(SessionCreated(...))` are called — matching the bus-and-store pairing the rest of the runtime uses (verify against `runtime.py` emit sites). `SessionCreated` accepts only `session_id` — `BaseEvent` config is `extra="forbid"` per [`schemas.py:23`](kaji/sdk/kaji/infra/events/schemas.py:23).
- **Text source**: `text` is built from `AgentMessageCompleted.content` joined across iterations, NOT from `AgentMessageDelta.delta` accumulation. Rationale: `AgentMessageCompleted` is the canonical per-iteration content event ([`schemas.py: class AgentMessageCompleted`](kaji/sdk/kaji/infra/events/schemas.py) — `content: str`) and is emitted exactly once per loop iteration regardless of whether the provider streamed deltas. Using deltas would silently miss text from a provider that emits a single non-delta chunk.
- **Error semantics**: `turn` propagates `send` / loop errors unchanged. `UnknownToolError`, `ProviderAPIError`, `CancellationError`, and `asyncio.CancelledError` all bubble. `turn` is a wrapper, not an error sink.
- `text`: empty string is a valid result (provider may return only a tool call). Test both.

```python
import uuid
from dataclasses import dataclass

from kaji.infra.events.schemas import KajiEvent, SessionCreated
from kaji.infra.events.types import EventType


@dataclass(frozen=True)
class TurnResult:
    text: str
    tool_call_events: list[KajiEvent]
    session_id: str
    events: list[KajiEvent]


# inside class AgentRuntime:
async def turn(
    self,
    prompt: str,
    *,
    session_id: str | None = None,
) -> TurnResult:
    sid = session_id or uuid.uuid4().hex
    existing = await self.store.get_events(sid)
    if not existing:
        created = SessionCreated(session_id=sid)
        await self.store.append(created)
        await self.bus.publish(created)
    snapshot_len = len(existing)
    await self.send(sid, prompt)
    all_events = await self.store.get_events(sid)
    turn_events = all_events[snapshot_len:]
    text = "".join(
        getattr(e, "content", "")
        for e in turn_events
        if e.type == EventType.AGENT_MESSAGE_COMPLETED
    )
    tool_call_events = [
        e for e in turn_events if e.type == EventType.TOOL_CALL_REQUESTED
    ]
    return TurnResult(
        text=text,
        tool_call_events=tool_call_events,
        session_id=sid,
        events=turn_events,
    )
```

```ts
async turn(
  prompt: string,
  opts: { sessionId?: string } = {},
): Promise<{
  text: string;
  toolCallEvents: KajiEvent[];
  sessionId: string;
  events: KajiEvent[];
}> {
  const sessionId = opts.sessionId ?? crypto.randomUUID();
  const existing = await this.store.getEvents(sessionId);
  if (existing.length === 0) {
    const created = KajiEvent.parse({ type: EventType.SESSION_CREATED, session_id: sessionId });
    await this.store.append(created);
    await this.bus.publish(created);
  }
  const snapshotLen = existing.length;
  await this.send(sessionId, prompt);
  const all = await this.store.getEvents(sessionId);
  const turnEvents = all.slice(snapshotLen);
  const text = turnEvents
    .filter((e) => e.type === EventType.AGENT_MESSAGE_COMPLETED)
    .map((e) => ("content" in e ? e.content : ""))
    .join("");
  const toolCallEvents = turnEvents.filter(
    (e) => e.type === EventType.TOOL_CALL_REQUESTED,
  );
  return { text, toolCallEvents, sessionId, events: turnEvents };
}
```

```ts
import { readFileSync, existsSync, mkdirSync, copyFileSync } from "node:fs";
import { join, dirname } from "node:path";

export interface AddOptions {
  registryRoot: string;
  log?: (msg: string) => void;
}

export async function add(argv: string[], opts: AddOptions): Promise<number> {
  const log = opts.log ?? console.log;
  const name = argv[0];
  if (!name) {
    log("usage: kaji add <name> [--out <dir>] [--force]");
    return 1;
  }
  let out = "./integrations";
  let force = false;
  for (let i = 1; i < argv.length; i++) {
    if (argv[i] === "--out") out = argv[++i] ?? out;
    else if (argv[i] === "--force") force = true;
  }
  const indexPath = join(opts.registryRoot, "index.json");
  if (!existsSync(indexPath)) {
    log(`Registry index missing at ${indexPath}`);
    return 1;
  }
  const index = JSON.parse(readFileSync(indexPath, "utf8")) as {
    integrations?: Record<string, string>;
  };
  const rel = index.integrations?.[name];
  if (!rel) {
    const available = Object.keys(index.integrations ?? {}).sort().join(", ") || "(none)";
    log(`Unknown integration: '${name}'. Available: ${available}`);
    return 1;
  }
  const manifestPath = join(opts.registryRoot, rel);
  if (!existsSync(manifestPath)) {
    log(`Manifest missing: ${manifestPath}`);
    return 1;
  }
  const manifest = JSON.parse(readFileSync(manifestPath, "utf8")) as {
    name: string; version: string; namespace: string; description: string;
    auth: { kind: string; env?: string };
    files: string[];
    tools: { name: string; description: string }[];
  };
  for (const key of ["name", "version", "namespace", "description", "auth", "files", "tools"]) {
    if (!(key in manifest)) {
      log(`Manifest missing key '${key}' at ${manifestPath}`);
      return 1;
    }
  }
  const tsFiles = manifest.files.filter((f) => f.endsWith(".ts"));
  if (tsFiles.length === 0) {
    log(`Skipping '${name}': no TypeScript source files in this integration (Python only).`);
    return 0;
  }
  mkdirSync(out, { recursive: true });
  for (const f of tsFiles) {
    const src = join(dirname(manifestPath), f);
    const dest = join(out, f);
    if (existsSync(dest) && !force) {
      log(`File exists: ${dest} (use --force to overwrite)`);
      return 1;
    }
    mkdirSync(dirname(dest), { recursive: true });
    copyFileSync(src, dest);
  }
  log(`Wrote ${tsFiles.length} file(s) to ${out}`);
  return 0;
}
```

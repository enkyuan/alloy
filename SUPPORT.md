# Support

## Support boundary

Use https://github.com/enkyuan/alloy/issues for reproducible Kaji SDK bugs and
documentation feedback. General architecture consulting, application code,
experimental integrations, untested package managers, and provider account
issues are outside the support boundary. Security reports must use the private
channel in [SECURITY.md](SECURITY.md).

Beta support is best effort. Include the SDK language/version, runtime and
compiler versions, package manager, operating system, stable error code, and a
minimal redacted reproduction. Never attach keys, prompts, tool
arguments/results, arbitrary metadata, or raw provider bodies.

## DX review

The Kaji maintainer (`@enkyuan`) owns the 30-day post-publication DX review.
The planning checkpoint is 2026-08-11, or exactly 30 days after publication if
publication occurs later. During the beta window, the same owner runs a monthly
friction audit on the first business day and records docs feedback, validated
automated-onboarding regressions, and follow-up dates in the issue tracker.

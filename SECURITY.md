# Security policy

## Private vulnerability reports

Do not open a public issue for a suspected vulnerability or include public
exploit details. Use the repository's private vulnerability channel:
https://github.com/enkyuan/alloy/security/advisories/new.

Include affected Kaji package/version, impact, minimal reproduction, and only
the redacted event fields needed to reproduce it. Remove prompts, tool
arguments/results, arbitrary metadata, credentials, tokens, provider bodies,
and raw user data.

## Supported beta versions

Supported beta versions are the newest Python and TypeScript versions listed
as published and byte-verified in the canonical release matrix. Older betas
receive fixes only when the maintainer explicitly marks them supported.
Unpublished source snapshots are not supported release versions.

## Response expectations

Reports are handled on a best-effort basis. The target is an acknowledgement
within three business days and an initial triage response within seven business
days. Complex or coordinated disclosures may take longer. The maintainer will
agree on disclosure timing before public details are released.

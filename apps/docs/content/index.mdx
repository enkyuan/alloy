agentkit is an embeddable SDK for building agents. The core needs no database
or server. Run `agentkit-serve` when you want multi-process durability and
real-time voice.

## Packages

| Package          | Path             | What it is                                   |
| ---------------- | ---------------- | -------------------------------------------- |
| `agentkit`       | `agentkit/sdk`   | Python SDK: core runtime, embed anywhere     |
| `agentkit-serve` | `agentkit/serve` | Python: FastAPI + workers, reference service |
| `@agentkit/sdk`  | `agentkit/ts`    | TypeScript port of the core runtime          |

The wire format (event-type strings, field names) is identical across the
Python SDK and the TypeScript port, so logs round-trip between them.

## Embed or serve?

| If you want…                                      | Use              |
| ------------------------------------------------- | ---------------- |
| In-process agent in your own app, no infra        | `agentkit`       |
| Multi-process durability, real-time voice over WS | `agentkit-serve` |

See [reference service](/docs/reference-service) for the multi-process layout.

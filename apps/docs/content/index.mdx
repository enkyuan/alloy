Kaji is an embeddable SDK for building agents. The stable core needs no
database or server. Run `kaji-serve` only when you need its experimental REST
or Soniox speech-to-text edge.

## Packages

| Package      | Path         | What it is                                         |
| ------------ | ------------ | -------------------------------------------------- |
| `kaji`       | `kaji`       | Python SDK: stable core plus experimental add-ons  |
| `@kaji/sdk`  | `kaji/ts`    | TypeScript SDK: stable core and copyable catalog   |
| `@kaji/cli`  | `apps/cli`   | Standalone cross-language scaffold and diagnostics |
| `kaji-serve` | `kaji/serve` | Experimental REST + Soniox STT reference service   |

The wire format (event-type strings, field names) is identical across the
Python SDK and the TypeScript port, so logs round-trip between them.

## Embed or serve?

| If you want…                                   | Use          |
| ---------------------------------------------- | ------------ |
| In-process agent in your own app, no infra     | `kaji`       |
| REST routes or real-time transcription over WS | `kaji-serve` |

See [reference service](/docs/reference-service) for the supported edge surface.

## Composition

Kaji's core is a set of primitives: events, sessions, tools, providers, and
runtime. It does not pick a vendor for you: Python configuration and generated
scaffolds select the in-memory mock by default, not a third-party service. Both
SDKs also package a source-owned integration catalog. `echo` is the only beta
catalog entry; GitHub and the TypeScript-only filesystem, HTTP, SQLite, and web
entries remain explicit opt-in experiments.

For the 0.2 beta candidate, the Python SDK still bundles a few opinionated
modules for convenience: `kaji.cli` (project scaffolding),
`kaji.knowledge` (RAG building blocks), `kaji.modalities.voice`
(STT / TTS edges), and `kaji.infra.observability` (metrics, tracing).
Only observability is part of the stable core; RAG, voice, Redis realtime, and
native Gemini/Kimi remain experimental Python-only surfaces.

See [integrations](/docs/integrations) for the exact catalog and the explicit
Gmail hold.

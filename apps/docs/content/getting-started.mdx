title: Getting Started
description: Install the local Kaji TypeScript alpha candidate, define a typed tool, and inspect an agent turn end to end.
---

This tutorial verifies capability execution without credentials in both SDKs,
then configures OpenAI and a risk-classified tool on the Python side. The
retained TypeScript product is the one-shot `Kaji.execute` capability surface;
live providers remain a Python path.

<Steps>
  <Step>
    ### Install the local alpha candidate

    ```bash
    mkdir kaji-quickstart
    cd kaji-quickstart
    npm init -y
    npm install ./irogane-kaji-0.3.0-alpha.1.tgz zod
    npm install --save-dev tsx@4.22.4
    ```

    The local `irogane-kaji-0.3.0-alpha.1.tgz` release candidate is not public on npm. The pinned `tsx` development dependency runs TypeScript
    consistently across the supported Node 22 and 24 lines. If this project
    uses Bun, replace both install commands with
    `bun add ./irogane-kaji-0.3.0-alpha.1.tgz zod`; Bun runs `.mts` files directly. Python
    is not published to PyPI for this release. You do not need a provider key
    for the first run.

  </Step>

  <Step>
    ### Verify the local runtime

    Start with the deterministic mock provider. This separates package and
    runtime setup from network and credential failures.

    {/* getting-started:no-key:typescript:start */}
    ```ts
    import { Kaji, capability, capabilityResult } from "@irogane/kaji";
    import * as z from "zod";

    const echo = capability({
      name: "echo",
      description: "Echo the provided message back.",
      input: z.object({ message: z.string() }),
      risk: "read",
      execute: async (input) => capabilityResult({ message: input.message }),
    });
    const result = await Kaji.execute({
      capability: echo,
      input: { message: "Hello, Kaji." },
      principal: "local-user",
    });
    console.log(JSON.stringify(result.value));
    ```
    {/* getting-started:no-key:typescript:end */}

    Save the example as `kaji.mts`, then run it:

    ```bash
    npm exec -- tsx kaji.mts
    # or: bun kaji.mts
    ```

    It prints `{"message":"Hello, Kaji."}`, the capability result value.

    The Python distribution is unavailable from PyPI for this release. From a
    [source checkout](/docs/install#source-checkout), the same no-key proof
    keeps risk and caller identity explicit. `AgentBuilder` wires a provider
    and tools to the runtime's event journal:

    {/* getting-started:no-key:python:start */}
    ```python
    import asyncio

    import kaji


    @kaji.function_tool(description="Return a local status.", risk="read")
    async def local_status() -> dict:
        return {"status": "ready"}


    async def main() -> None:
        runtime = (
            kaji.AgentBuilder()
            .provider(kaji.get_provider("mock", reply="mock"))
            .tool(local_status)
            .default_context(kaji.TurnContext(principal_id="docs-source"))
            .build()
        )
        try:
            result = await runtime.turn("Say hello.")
            print(result.text)
        finally:
            runtime.close()


    asyncio.run(main())
    ```
    {/* getting-started:no-key:python:end */}

    Save the Python example as `kaji/packages/py/smoke.py`, then run it:

    ```bash
    uv sync --project kaji/packages/py
    uv run --project kaji/packages/py python kaji/packages/py/smoke.py
    ```

  </Step>

  <Step>
    ### Configure OpenAI (Python)

    Live providers are a Python path in this release. Export the credential,
    then switch the quickstart's mock factory for the OpenAI factory:

    ```bash
    export OPENAI_API_KEY=sk-...
    ```

    The `kaji.get_provider("openai")` factory reads `OPENAI_API_KEY`. Load the
    variable with your application's environment tooling. OpenAI is the
    recommended live-provider path. Anthropic, Gemini, Kimi, and OpenRouter
    are implemented but remain WIP.

  </Step>

  <Step>
    ### Run a live tool loop (Python)

    Change the Python quickstart's provider line and give the tool a caller
    identity:

    ```python
    runtime = (
        kaji.AgentBuilder()
        .provider(kaji.get_provider("openai"))
        .tool(local_status)
        .default_context(kaji.TurnContext(principal_id="docs-source"))
        .build()
    )
    ```

    `turn()` records the user message, calls the provider, validates and
    dispatches any selected tool, and returns the final assistant text.

  </Step>
</Steps>

The Python SDK implements the shared event and tool contracts, but it is not
the primary path in this tutorial. The distribution is not available from
PyPI for this release. See the [Python source setup](/docs/install#python-sdk)
for Python-specific commands.

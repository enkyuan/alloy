---
title: Getting Started
description: Install agentkit, define a tool, and run an agent turn end-to-end. Python and TypeScript.
---

This page takes you from `install` to a working agent in five steps. By the
end you'll have sent a user message and received a model response, with one
tool wired in.

<Steps>
  <Step>
    ### Install

    <Tabs items={["python", "typescript"]}>
      <Tab value="python">
        ```bash
        pip install "agentkit[openai]"
        ```
      </Tab>
      <Tab value="typescript">
        ```bash
        bun add @agentkit/sdk openai
        ```
      </Tab>
    </Tabs>

    These pull the SDK plus one provider client. For other providers or
    optional extras, see [install](/docs/install).

  </Step>

  <Step>
    ### Set a provider key

    Pick one provider and export its key. The default in Python is `kimi`
    (OpenRouter); the TypeScript SDK ships `openai` and `anthropic`.

    ```bash
    export OPENAI_API_KEY=sk-...        # or
    export ANTHROPIC_API_KEY=sk-ant-... # or
    export KIMI_API_KEY=...              # Python default
    ```

    To override the Python default, set `AGENTKIT_MODEL_PROVIDER=openai`.

  </Step>

  <Step>
    ### Define a tool

    Tools are a spec (name, description, JSON-schema parameters) plus a
    handler. The `@function_tool` decorator (Python) / `functionTool(...)`
    helper (TS) derives the spec from type hints and the docstring.

    <Tabs items={["python", "typescript"]}>
      <Tab value="python">
        ```python
        from agentkit import function_tool

        @function_tool
        async def get_weather(city: str) -> dict:
            """Look up the weather for a city."""
            return {"city": city, "tempF": 68}
        ```
      </Tab>
      <Tab value="typescript">
        ```ts
        import { functionTool } from "@agentkit/sdk";
        import { z } from "zod";

        const getWeather = functionTool(
          {
            name: "get_weather",
            description: "Look up the weather for a city.",
            parameters: z.object({ city: z.string() }),
          },
          async ({ city }) => ({ city, tempF: 68 }),
        );
        ```
      </Tab>
    </Tabs>

  </Step>

  <Step>
    ### Build the runtime

    `AgentBuilder` wires a provider, tools, and an in-memory bus + store into
    a runnable `AgentRuntime`.

    <Tabs items={["python", "typescript"]}>
      <Tab value="python">
        ```python
        from agentkit import AgentBuilder, get_provider

        runtime = (
            AgentBuilder()
            .provider(get_provider("openai"))
            .tool(get_weather)
            .system_prompt("You are a helpful assistant.")
            .build()
        )
        ```
      </Tab>
      <Tab value="typescript">
        ```ts
        import { AgentBuilder, OpenAIProvider } from "@agentkit/sdk";

        const runtime = new AgentBuilder()
          .provider(new OpenAIProvider({ apiKey: process.env.OPENAI_API_KEY! }))
          .tool(getWeather)
          .systemPrompt("You are a helpful assistant.")
          .build();
        ```
      </Tab>
    </Tabs>

    No DB. No server. The runtime holds an `InMemoryEventStore` and
    `InMemoryEventBus` by default.

  </Step>

  <Step>
    ### Send a message

    `send()` appends a `UserMessage` to the event log and runs one turn. The
    model decides whether to call your tool; the runtime dispatches it,
    collects the result, and produces a final response.

    <Tabs items={["python", "typescript"]}>
      <Tab value="python">
        ```python
        import asyncio

        async def main():
            await runtime.send("session-1", "What's the weather in NYC?")
            for event in await runtime.history("session-1"):
                print(event.type, getattr(event, "content", ""))

        asyncio.run(main())
        ```
      </Tab>
      <Tab value="typescript">
        ```ts
        await runtime.send("session-1", "What's the weather in NYC?");
        for (const event of await runtime.history("session-1")) {
          console.log(event.type, event.content ?? "");
        }
        ```
      </Tab>
    </Tabs>

    To stream events as they happen instead of reading them after the turn,
    subscribe to the bus. See [event bus](/docs/concepts/event-bus).

  </Step>
</Steps>

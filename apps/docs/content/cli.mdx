---
title: CLI
description: The kaji CLI scaffolds projects, generates tool stubs from OpenAPI specs, and inspects your environment. Same commands in Python and TypeScript.
---

The CLI ships in two parity packages: `kaji` (Python, `pip install
kaji`) and `@kaji/cli` (TypeScript, `bun add -D @kaji/cli`).
Run `kaji --help` to see the live list.

## Commands

| Command   | Purpose                                                   | Python | TS  |
| --------- | --------------------------------------------------------- | ------ | --- |
| `init`    | Scaffold a runnable `turn()` agent project                | ✓      | ✓   |
| `gen`     | Generate tool stubs from an OpenAPI spec                  | ✓      | ✓   |
| `info`    | Show environment + installed kaji packages                | ✓      | ✓   |
| `secret`  | Generate a random 32-byte hex secret                      | ✓      | ✓   |
| `doctor`  | Check the environment for common issues                   | ✓      | ✓   |
| `upgrade` | Upgrade installed kaji packages                           | ✓      | ✓   |
| `mcp`     | Explain MCP setup status; server support is deferred      | --     | ✓   |

## init

```bash
kaji init --cwd ./my-agent --lang ts --provider openai --yes
cd ./my-agent
bun install
export OPENAI_API_KEY=sk-...
bun start
```

```bash
kaji init --cwd ./my-agent --lang python --provider openai --yes
cd ./my-agent
python -m pip install -r requirements.txt
export OPENAI_API_KEY=sk-...
python agent.py
```

TypeScript scaffolds write `package.json`, `tsconfig.json`, `agent.ts`, and
`.env.example`. Python scaffolds write `agent.py`, `requirements.txt`, and
`.env.example`. Both generated agents use the high-level
`turn("Say hello.")` API. `--force` overwrites; `--yes` skips the interactive
prompts. OpenAI `gpt-5.4-mini` is the recommended first live model in the SDK
readiness tests, and live tests skip when provider keys are absent.

## gen

```bash
kaji gen --spec openapi.yaml --out tools/ --lang python
kaji gen --spec openapi.yaml --out tools/ --lang ts
```

Parses an OpenAPI 3.x spec and emits one tool spec + handler per
`operationId`. The Python emitter writes `tools.py` (using `httpx`); the
TypeScript emitter writes `index.ts` (using `fetch`).

## info / doctor

```bash
kaji info                # shows platform, node/python, packages, providers
kaji info --json         # machine-readable
kaji doctor              # exit 1 if anything is wrong
```

`doctor` returns a non-zero exit code if any hard check fails. It detects the
scaffold language, checks Node >=22 for TypeScript, Python >=3.11 for Python,
the expected SDK/provider package, and the provider key selected by
`KAJI_MODEL_PROVIDER`.

## secret / upgrade

```bash
kaji secret              # prints KAJI_SECRET=<64 hex chars>
kaji secret --json
kaji upgrade -y          # bumps @kaji/* (TS) or kaji/kaji-* (PyPI)
```

## mcp (TypeScript only)

```bash
kaji mcp                 # prints current MCP setup status
```

`@kaji/cli` does not ship an MCP server yet, so this command does not write
AI-tool configuration. Use `kaji gen` to generate tool handlers today. MCP
server support is planned separately.

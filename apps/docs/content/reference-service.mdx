`agentkit-serve` (`agentkit/serve`) wraps the SDK as three processes over
Redis so heavy tool execution never stalls a real-time exchange.

| Process      | Role                                                      |
| ------------ | --------------------------------------------------------- |
| `api`        | FastAPI app: REST routes and STT WebSocket                |
| `bus-worker` | reasoning loop: LLM calls, event bus, tool dispatch       |
| `worker`     | async tool execution (TaskIQ), results back to bus-worker |

Redis Streams provide durable at-least-once hand-off between processes. Redis
Pub/Sub fans agent responses out to the connected client in real time.

Reach for this when you need multi-process durability or real-time voice over
a WebSocket. For in-process agents, embed the SDK directly — see the
[index](/docs).

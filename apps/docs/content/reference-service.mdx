title: Experimental Reference Service
description: kaji-serve is a pre-beta FastAPI and Soniox STT edge. It is not part of the supported 0.2 SDK beta.
---

`kaji-serve` (`kaji/serve`) exposes one FastAPI process with REST routes and a
Soniox speech-to-text WebSocket on port 8080. It is an experimental reference
edge, not part of the 0.2 SDK beta core or a production durability or
horizontal-scaling claim.

The STT socket authenticates the caller, accepts audio frames, and returns
partial, final, and complete transcripts. It does not queue an agent command,
run `AgentRuntime`, relay an agent response, or synthesize speech. Applications
own the explicit hand-off from a final transcript to the embedded SDK runtime.

## Run with docker compose

The fastest path. It starts the API and its Postgres/Supabase dependencies.

```bash
cd docker/kaji
docker compose up
```

The `api` is reachable at `http://localhost:8080`. Health check:

```bash
curl http://localhost:8080/health
```

## Run directly

If its dependencies are already available, start the single API process:

```bash
cd kaji/serve
uv sync
uv run uvicorn kaji_serve.server.app:app --host 0.0.0.0 --port 8080
```

## When to use the reference service

Use it only to evaluate:

- the current FastAPI service shell,
- real-time Soniox transcription over a WebSocket,
- service migration requirements before a supported hosted beta.

For agent execution and embedded apps, use the SDK directly. A future hosted
runtime needs a canonical adapter, persistent event store, restart-safe tool
idempotency, and distributed same-session coordination. See [index](/docs).

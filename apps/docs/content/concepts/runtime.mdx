---
title: Runtime
description: AgentBuilder configures the runtime; AgentRuntime.turn runs the high-level user-message path; AgentRuntime.history reads back the event log.
---

`AgentRuntime` is the loop that takes a user message, calls the LLM,
dispatches tool calls scatter-gather, and projects the resulting events
into session state. You build one with `AgentBuilder`.

## AgentBuilder

| Method                       | Description                                                                                                                                   |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `.provider(p)`               | Sets the LLM provider (required).                                                                                                             |
| `.tool(t)`                   | Adds one tool. Call multiple times for multiple tools.                                                                                        |
| `.integration(i)`            | Adds an `Integration` that registers a bundle of tools.                                                                                       |
| `.system_prompt(s)` (Python) | Sets the system prompt. `.systemPrompt(s)` in TypeScript.                                                                                     |
| `.strategy(s)`               | Overrides loop strategy (e.g. max iterations).                                                                                                |
| `.policy(p)`                 | Attaches a `ToolPolicy` for risk-based approval.                                                                                              |
| `.build(bus?, store?)`       | Builds the runtime. `bus` and `store` are optional keyword/option args, not separate fluent calls; both default to in-memory implementations. |

## AgentRuntime

| Method                   | Returns                                    | Description                                                                |
| ------------------------ | ------------------------------------------ | -------------------------------------------------------------------------- |
| `turn(text)`             | turn result                                | High-level path for one user message and model/tool loop.                  |
| `send(session_id, text)` | `None` / `Promise<void>`                   | Lower-level session API: append a `USER_MESSAGE` and run one turn.         |
| `history(session_id)`    | `list[KajiEvent]` / `Promise<KajiEvent[]>` | All events appended to this session, in order.                             |

In Python, methods are snake_case (`send`, `history`) and async. In
TypeScript they are camelCase (`send`, `history`) and return Promises.

## Example

<Tabs items={["python", "typescript"]}>
  <Tab value="python">
    ```python
    from kaji import AgentBuilder, get_provider

    runtime = (
        AgentBuilder()
        .provider(get_provider("openai"))
        .system_prompt("You are a helpful assistant.")
        .build()
    )
    result = await runtime.turn("Hello")
    print(result.text)
    ```

  </Tab>
  <Tab value="typescript">
    ```ts
    import { AgentBuilder, OpenAIProvider } from "@kaji/sdk";

    const runtime = new AgentBuilder()
      .provider(new OpenAIProvider({ apiKey: process.env.OPENAI_API_KEY! }))
      .systemPrompt("You are a helpful assistant.")
      .build();
    const result = await runtime.turn("Hello");
    console.log(result.text);
    ```

  </Tab>
</Tabs>

See [event bus](/docs/concepts/event-bus) for the underlying mechanism.

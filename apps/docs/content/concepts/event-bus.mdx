---
title: Event Bus
description: The event bus fans events out to per-session subscribers. In-memory by default in both SDKs; Redis Streams in kaji-serve for cross-process hand-off.
---

Subscribe to the bus when you want to stream events as they happen -- e.g.
push agent deltas to a UI, or tee them into your own log.

The default implementation is in-memory (`InMemoryEventBus` in Python,
`EventBus` in TS), sufficient for embedded single-process agents.
`kaji-serve` swaps in a Redis Stream-backed bus for cross-process
hand-off. Durable event replay still requires a persistent event store.

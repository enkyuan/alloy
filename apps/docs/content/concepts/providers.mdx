title: Providers

Pick a provider when you build the runtime. The runtime never imports
provider-specific types: translation happens at the provider boundary
against a neutral message and tool-spec format.

## LLM providers

| Provider    | Python SDK | TypeScript SDK            | Env var              |
| ----------- | ---------- | ------------------------- | -------------------- |
| `openai`    | ✓          | ✓                         | `OPENAI_API_KEY`     |
| `anthropic` | ✓          | ✓                         | `ANTHROPIC_API_KEY`  |
| `kimi`      | ✓          | OpenAI-compatible factory | `OPENROUTER_API_KEY` |
| `gemini`    | ✓          | OpenAI-compatible factory | `GEMINI_API_KEY`     |
| `mock`      | ✓          | -                         | -                    |

The base Python SDK defaults to `mock` for tests. Select a real Python
provider via `KAJI_MODEL_PROVIDER`; TypeScript callers choose a provider
factory in code. `OpenRouter`, Kimi, and Gemini factories in TypeScript reuse
the OpenAI-compatible transport and do not expose native vendor features.
TypeScript Kimi requires an explicit `apiKey` or `OPENROUTER_API_KEY`;
TypeScript Gemini falls back to `GOOGLE_API_KEY`.
Adding a provider means implementing the `ModelProvider` protocol and
registering it with `register_provider` (`registerProvider` in TS).

## Custom-provider cancellation contract

Custom providers are cooperative in-process boundaries. While opening a
request and while streaming, they must observe the runtime-provided
`cancellation_token` / `cancellationToken`, stop the underlying request, and
let the stream iterator settle when cancellation is requested. They must also
support the runtime closing that iterator after partial output.

If a provider remains active beyond the configured cancellation grace, Kaji
raises `PROVIDER_CANCELLATION_CONTRACT_VIOLATION` and quarantines that session
until `drain_providers()` / `drainProviders()` confirms settlement. Closing the
runtime rejects new turns; it cannot force-kill hostile in-process code. Run
the same cancellation-contract suite used by the built-in adapters before
describing a custom provider as production-safe.

## TTS and STT

TTS providers (`gemini`, `openai`, `none`) implement `TTSProvider`. STT uses
Soniox by default. Both attach at the voice edges of the runtime; the
reasoning loop itself is modality-agnostic.

---
title: Providers
description: LLM, TTS, and STT providers implement common interfaces. The Python SDK ships kimi, openai, anthropic, gemini, and mock. The TypeScript SDK ships openai and anthropic.
---

Pick a provider when you build the runtime. The runtime never imports
provider-specific types: translation happens at the provider boundary
against a neutral message and tool-spec format.

## LLM providers

| Provider    | Python SDK  | TypeScript SDK | Env var             |
| ----------- | ----------- | -------------- | ------------------- |
| `openai`    | ✓           | ✓              | `OPENAI_API_KEY`    |
| `anthropic` | ✓           | ✓              | `ANTHROPIC_API_KEY` |
| `kimi`      | ✓ (default) | -              | `KIMI_API_KEY`      |
| `gemini`    | ✓           | -              | `GEMINI_API_KEY`    |
| `mock`      | ✓           | -              | -                   |

Select the Python default via `AGENTKIT_MODEL_PROVIDER`. Adding a provider
means implementing the `ModelProvider` protocol and registering it with
`register_provider` (`registerProvider` in TS).

## TTS and STT

TTS providers (`gemini`, `openai`, `none`) implement `TTSProvider`. STT uses
Soniox by default. Both attach at the voice edges of the runtime; the
reasoning loop itself is modality-agnostic.

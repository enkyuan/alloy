---
title: Session State
description: replaySession deterministically projects an event log into a SessionState (isActive and the message history) that gets passed to the LLM.
---

The runtime calls `replaySession` for you on every turn. Call it directly when
you want to inspect a session's current state or rebuild state from a stored
log.

`replaySession` (Python: `ReplaySession`) takes the event log for a session
and projects it into a `SessionState`: `isActive` (Python: `is_active`) and
`messages`, the conversation history in `{ role, content }` form passed to
the LLM.

State is a pure projection of the log, so replay is deterministic: the same
events always yield the same `SessionState`.

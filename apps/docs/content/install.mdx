Kaji's protected npm release candidate is TypeScript `0.2.0-beta.6`. It is not
available from the public registry until protected publication and exact-byte
verification succeed, so use the source checkout for now. Python wheel and
PyPI publication are deferred for this release. Both SDKs share the
stable-core wire format. All `0.x` releases are pre-1.0, so pin exact versions
in production.

## TypeScript

The candidate declares Zod `>=4.3 <5` as a required peer and OpenAI `>=4 <8`
as an optional peer. The public registry command will be documented after the
npm artifact passes exact-byte verification.

## Source checkout

Clone the repository to run the TypeScript quickstart, develop against either
SDK, or run the full workspace checks:

```bash
git clone https://github.com/enkyuan/alloy.git
cd alloy
bun install --frozen-lockfile
bun run --cwd kaji/ts test:quickstart
```

The final command runs the deterministic TypeScript quickstart without a
provider credential.

## TypeScript contract

The package declares `zod >=4.3 <5` as a required peer. `openai >=4 <8` is
optional; omit it when you only use `MockProvider` from `kaji-sdk/testing`.
Zod 3 and Zod 5 are outside the declared beta range.

| Requirement  | Verified release snapshot |
| ------------ | ------------------------- |
| Runtime      | Node.js 22 or 24          |
| TypeScript   | 5.7.3 and 6.0.2           |
| Package tool | npm or Bun                |

pnpm and Yarn are outside the tested package matrix. Anthropic, Gemini, Kimi,
and OpenRouter are WIP; their machine contract tier is `experimental`. See
[providers](/docs/concepts/providers) before choosing one.

## CLI

The TypeScript package declares a `kaji` binary:

```bash
bunx kaji --help
```

The CLI scaffolds TypeScript projects and manages the packaged integration
registry. See [CLI commands](/docs/cli#typescript-sdk-cli) and the separate
Python and standalone CLI surfaces.

## Python SDK

The Python project version in this checkout is `0.2.0b1`. It is unavailable
from PyPI for this release, so there is no public registry-install command.

For source-checkout development, install the Python project with uv:

```bash
uv sync --project kaji --extra openai
uv run --project kaji python -c "import kaji; print(kaji.__name__)"
```

Python imports use `kaji`, and its CLI uses the `kaji` binary name. The SDK
shares the v1 event schema but includes additional WIP surfaces outside the
TypeScript beta path.

## Version policy

| Range   | Behavior                                                |
| ------- | ------------------------------------------------------- |
| `0.x.y` | Pre-1.0. Minor bumps may rename or remove public names. |

Pin the exact beta version you validate. The Python and TypeScript packages in
this checkout validate the same v1 event schema.

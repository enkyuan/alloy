---
title: Install
description: Install kaji in Python or TypeScript, pick the provider extras you need, and learn the v0.x compatibility policy.
---

kaji ships as two SDKs that share the stable-core wire format. Install one per
app and pick provider extras as needed. The release implementation remains
pre-beta until protected evidence passes; all `0.x` releases are pre-1.0, so
minor versions may break the public surface. Pin exact versions in production.

## Python

```bash
pip install "kaji[openai]"          # one provider
pip install "kaji[openai,anthropic]" # multiple
pip install "kaji[providers]"        # all three: openai, anthropic, gemini
```

The base install has no provider deps. `kaji[openai]` adds the `openai`
client, `kaji[anthropic]` adds `anthropic`, `kaji[gemini]` adds
`google-genai`. The base SDK defaults to the mock provider for tests; choose
a real provider with `KAJI_MODEL_PROVIDER` or a scaffold generated by
`kaji init`. Kimi/OpenRouter speaks the OpenAI chat-completions wire format
and uses `KIMI_API_KEY`.

Optional extras:

| Extra          | Adds                                           |
| -------------- | ---------------------------------------------- |
| `openai`       | `openai`                                       |
| `anthropic`    | `anthropic`                                    |
| `gemini`       | `google-genai`                                 |
| `providers`    | all of the above                               |
| `realtime`     | `redis` (for `kaji-serve`)                     |
| `google-tools` | Google API clients for out-of-tree OAuth tools |
| `dev-ui`       | `rich` (for prettier CLI output)               |

## TypeScript

```bash
bun add @kaji/sdk "zod@>=4.3 <5" openai
bun add @kaji/sdk "zod@>=4.3 <5" @anthropic-ai/sdk
```

`zod >=4.3 <5` is a required peer dependency of `@kaji/sdk`. `openai >=4 <8`
and `@anthropic-ai/sdk >=0.30 <2` are optional peers; install whichever you'll
register as a provider. Zod 3 and Zod 5 are outside the supported beta range.

The no-key scaffold installs only the exact `@kaji/sdk` version and supported
Zod range. OpenAI and Anthropic modes add only their selected provider peer.
Runtime support is Node 22 and 24; declarations compile with TypeScript 5.7.3
and current 6.x. npm and Bun are tested separately. pnpm and Yarn are not yet
claimed as supported package managers.

## CLI

Three packages expose a binary named `kaji`; their command sets are different.

```bash
pip install kaji       # Python SDK CLI: init/gen/add/list/info/doctor/...
bun add @kaji/sdk "zod@>=4.3 <5" # Embedded TS CLI: init/add/list/replay
bun add -D @kaji/cli   # Standalone cross-language scaffold + diagnostics
```

Only standalone `@kaji/cli` has `mcp`; it reports that server setup is deferred
and does not write AI-tool config. See [CLI](/docs/cli) for the exact command
matrix and flag differences.

## Version policy

| Range   | Behavior                                                |
| ------- | ------------------------------------------------------- |
| `0.x.y` | pre-1.0. Minor bumps may rename or remove public names. |
| `>=1.0` | semver. Public surface is stable across minor versions. |

Pin exact versions in lockfiles until 1.0 lands. The events wire format
(field names + type strings) is stable across SDKs in 0.x.

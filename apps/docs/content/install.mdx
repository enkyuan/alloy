The TypeScript package version in this checkout is `0.2.0-beta.2`, but that
version is not available from npm as of July 25, 2026. The Python distribution
is also unavailable from PyPI. Public package installation is WIP; use the
source setup below.

## Source checkout

Clone the repository and install its locked workspace dependencies:

```bash
git clone https://github.com/enkyuan/alloy.git
cd alloy
bun install --frozen-lockfile
bun run --cwd kaji/ts test:quickstart
```

The final command runs the deterministic TypeScript quickstart without a
provider credential.

## TypeScript contract

The package declares `zod >=4.3 <5` as a required peer. `openai >=4 <8` is
optional; omit it when you only use `MockProvider` from `kaji-sdk/testing`.
Zod 3 and Zod 5 are outside the declared beta range.

| Requirement  | Verified release snapshot |
| ------------ | ------------------------- |
| Runtime      | Node.js 22 or 24          |
| TypeScript   | 5.7.3 and 6.0.2           |
| Package tool | npm or Bun                |

pnpm and Yarn are outside the tested package matrix. Anthropic, Gemini, Kimi,
and OpenRouter are WIP; their machine contract tier is `experimental`. See
[providers](/docs/concepts/providers) before choosing one.

## CLI

The TypeScript package declares a `kaji` binary. Run the CLI from this checkout:

```bash
bun kaji/ts/src/cli/bin.ts --help
```

The source CLI scaffolds TypeScript projects and manages the packaged
integration registry. Generated projects still reference the unpublished npm
package, so their dependency setup is not runnable from the public registry.
See [CLI source commands](/docs/cli#typescript-sdk-cli) and the separate Python
and standalone CLI surfaces.

## Python SDK

The Python project version in this checkout is `0.2.0b1`. It is not available
from PyPI as of July 25, 2026, so there is no public registry-install command
for this snapshot.

For source-checkout development, install the Python project with uv:

```bash
uv sync --project kaji --extra openai
uv run --project kaji python -c "import kaji; print(kaji.__name__)"
```

Python imports use `kaji`, and its CLI uses the `kaji` binary name. The SDK
shares the v1 event schema but includes additional WIP surfaces outside the
TypeScript beta path.

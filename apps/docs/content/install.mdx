TypeScript `0.2.0-beta.11` is public on npm as
[`kaji`](https://www.npmjs.com/package/@irogane/kaji/v/0.2.0-beta.11). Python is
not published to PyPI for this release; repository release gates still build
and exercise wheel and source-distribution artifacts. Both SDKs share the
stable-core wire format. All `0.x` releases are pre-1.0, so pin exact versions
in production.

## TypeScript

Install the exact beta with the required Zod peer and the beta-supported
OpenAI adapter:

```bash
npm install @irogane/kaji@0.2.0-beta.11 zod openai
# or
bun add @irogane/kaji@0.2.0-beta.11 zod openai
```

The package declares Zod `>=4.3 <5` as a required peer and OpenAI `>=4 <8`
as an optional peer. Omit `openai` when you only use `MockProvider` from
`@irogane/kaji/testing`.

## Source checkout

Clone the repository to run the TypeScript quickstart, develop against either
SDK, or run the full workspace checks:

```bash
git clone https://github.com/enkyuan/alloy.git
cd alloy
bun install --frozen-lockfile
bun run --cwd kaji/packages/ts test:quickstart
```

The final command runs the repository's deterministic TypeScript quickstart
without a provider credential. Use this path when contributing to Kaji or
validating both SDKs together; application onboarding should use the published
package above.

## TypeScript contract

The package declares `zod >=4.3 <5` as a required peer. `openai >=4 <8` is
optional; omit it when you only use `MockProvider` from `@irogane/kaji/testing`.
Zod 3 and Zod 5 are outside the declared beta range.

| Protected evidence cell | Verified release snapshot                            |
| ----------------------- | ---------------------------------------------------- |
| Node 22                 | GitHub-hosted `ubuntu-22.04`, Linux/x64, npm and Bun |
| Node 24                 | GitHub-hosted `ubuntu-24.04`, Linux/x64, npm and Bun |
| TypeScript              | 5.7.3 and 6.0.3 in both cells                        |

pnpm and Yarn are outside the tested package matrix. Anthropic, Gemini, Kimi,
and OpenRouter are WIP; their machine contract tier is `experimental`. See
[providers](/docs/concepts/providers) before choosing one. These two protected
cells make no broader runtime or platform claim, including for macOS/arm64,
Windows, other Node versions, or fully offline dependency installation.

## CLI

The TypeScript package declares a `kaji` binary:

```bash
npm exec -- kaji --help
```

The CLI scaffolds TypeScript projects and manages the packaged integration
registry. See [CLI commands](/docs/cli#typescript-sdk-cli) and the separate
Python and standalone CLI surfaces.

## Python SDK

The Python project version in this checkout is `0.2.0b1`. It is unavailable
from PyPI for this release, so there is no public registry-install command.

For source-checkout development, install the Python project with uv:

```bash
uv sync --project kaji/packages/py --extra openai
uv run --project kaji/packages/py python -c "import kaji; print(kaji.__name__)"
```

Python imports use `kaji`, and its CLI uses the `kaji` binary name. The SDK
shares the v1 event schema but includes additional WIP surfaces outside the
TypeScript beta path.

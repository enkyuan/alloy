Tool calls execute sequentially by default. Only adjacent tools explicitly
marked `parallel_safe` may overlap, and that overlap is bounded by the
configured tool concurrency (four handlers by default).

## Modality boundary

The TypeScript beta implements the text path. Python provides WIP TTS adapters,
and `kaji-serve` separately exposes a WIP Soniox STT WebSocket. This checkout
does not compose those pieces into an end-to-end voice agent.

# Product

## Register

brand

## Platform

web

## Users

Developers evaluating or integrating Kaji in Python or TypeScript. They need to understand the runtime contract, install the correct package surface, and move from a deterministic local turn to bounded provider and tool integrations.

## Product Purpose

Explain Kaji as an embeddable, modality-agnostic agent runtime and provide a trustworthy path from installation through production-facing concepts, integrations, and operations.

## Positioning

Kaji gives application developers one event-sourced, bounded agent runtime across Python and TypeScript without forcing a hosted platform.

OpenAI is the sole primary model provider. Every other provider adapter is WIP; implementation or package availability must not be presented as a beta stability commitment.

## Conversion & proof

- Primary and secondary CTA: install Kaji, then follow the getting-started guide.
- The line a visitor remembers after 10 seconds: build bounded agents in Python or TypeScript.
- Belief ladder: Kaji is embeddable; its runtime is deterministic and observable; tools and providers have explicit boundaries; the same core contract exists in both SDKs.
- Proof on hand: the public `kaji@0.2.0-beta.11` npm artifact, checked onboarding examples, and SDK-sync validation.

## Brand Personality

Precise, quiet, and hand-crafted. The documentation should feel like a careful technical notebook rather than a generic product template.

## Anti-references

Avoid dashboard chrome, oversized SaaS marketing sections, decorative card grids, and documentation themes that obscure the reading flow. Agentation is the explicit visual and interaction reference.

## Design Principles

- Put readable, copyable technical content first.
- Let the implementation demonstrate the product's bounded, inspectable character.
- Keep navigation compact and predictable.
- Preserve one visual voice from overview through deep reference pages.
- Use interaction only where it removes friction.

## Accessibility & Inclusion

Support keyboard navigation, visible focus, semantic landmarks, readable contrast, responsive layouts, and reduced-motion preferences.

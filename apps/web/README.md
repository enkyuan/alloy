# @ryo/web

Studio -- the merchant-facing dashboard for Ryo. It lets merchants configure
agents, connect payment providers, and manage their account.

**Stack:** React 19, TypeScript, Vite, TanStack Router + Query + Form, Tailwind
CSS v4, shadcn/ui, Better Auth, and Zod.

## Running locally

```bash
# From the repository root
bun install
bun --filter @ryo/web dev # default port 5173
```

**Environment variables** (copy from `.env.example`):

| variable        | purpose                                                    |
| --------------- | ---------------------------------------------------------- |
| `VITE_API_URL`  | base url for `@ryo/api` (default `http://localhost:8090`)  |
| `VITE_AUTH_URL` | base url for `@ryo/auth` (default `http://localhost:8080`) |

## Routes

| path         | description                              |
| ------------ | ---------------------------------------- |
| `/`          | landing / redirect to dashboard or login |
| `/login`     | email + password sign-in                 |
| `/signup`    | account creation                         |
| `/dashboard` | agent list and org overview              |

`src/routeTree.gen.ts` is generated by the TanStack Router Vite plugin and is
intentionally ignored. Run the development server or a build before invoking
the standalone typecheck on a clean checkout.

## Development

```bash
bun run build      # production build
bun run typecheck  # tsc --noemit
bun run lint       # eslint
```

UI primitives (shadcn components) go in `src/components/ui/`.
